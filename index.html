06 · EL PROYECTO

Sobre Ludoteca

Ludoteca es un proyecto web creado para organizar información sobre videojuegos de una forma sencilla, visual y fácil de consultar.

La idea combina un catálogo interactivo con contenidos editoriales, noticias y pequeñas recomendaciones. Cada juego se presenta como una ficha dentro de un archivo digital.

El proyecto está desarrollado como práctica de tecnologías web dentro de Formación Profesional, utilizando HTML, CSS y JavaScript.

NOTA DEL ARCHIVISTA

"No todos los grandes juegos necesitan ser nuevos. Algunos solo necesitan que alguien vuelva a abrirlos."
